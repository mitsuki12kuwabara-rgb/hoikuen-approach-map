# チーム共有（Google スプレッドシート）の準備

保育園アプローチマップの記録を、チームのGoogleスプレッドシートに保存して全員で共有するための準備です。費用はかかりません。最初に1回だけやります（15分ほど）。

## しくみ

- 地図（GitHub Pages）は今までどおり誰でも開けます。**記録はスプレッドシートにだけ保存**し、地図のページには載せません。
- 地図を使う人は、最初に一度だけ **名前** と **チームの合言葉** を入れます。合言葉がないと記録の読み書きはできません。
- 記録は **園ごとに1行**（シート「記録」）。同じ園を同時に記録したら、**更新時刻が新しいほうが残ります**。
- 電話・訪問の履歴は **シート「履歴」** に記録者名つきで1件1行ずつ積み上がり、消えません。
- 電波が悪いときは端末にいったん保存し、つながったらまとめて送ります（画面右上が「⏳ 未送信」→「☁ 共有中」に変わります）。
- シート「集計」に段階ごとの園数が自動で出ます。グラフ・Excel出力はスプレッドシートの機能でできます。
- 誤って消したり上書きしたときは、スプレッドシートの「ファイル → 変更履歴」で戻せます。

## 手順

1. Googleドライブで新しいスプレッドシートを作り、名前を「保育園アプローチ記録」などにします。
2. メニュー「拡張機能 → Apps Script」を開き、最初からある中身を消して、このフォルダの `Code.gs` の中身を貼り付けて保存（💾）します。
3. スプレッドシートに戻って再読み込みすると、メニューに「保育園マップ」が出ます。
   - 「① 最初の準備（シートを作る）」→ 初回だけ Google の確認画面が出るので、自分のアカウントで「許可」します。
   - 「② 合言葉を決める・変える」→ チームの合言葉（8文字以上）を入れます。
4. Apps Script の画面で「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（合言葉で守ります）
   - 「デプロイ」を押し、出てきた **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピーします。
5. 地図のフォルダの `sync-config.js` の `""` の中にそのURLを入れて、GitHub に上げます。
6. 地図を開くと「チームで共有する」画面が出るので、名前と合言葉を入れて「つなぐ」。チームの人にも地図のURLと合言葉を伝えます。

## 運用のメモ

- **合言葉が漏れたら**：メニュー「② 合言葉を決める・変える」で変えます。全員の地図で「合言葉がちがいます」と出るので、新しい合言葉を入れ直してもらいます。
- **スプレッドシートを直接直したいとき**：表示用の列（段階・メモなど）は地図には戻りません。地図に反映させたい修正は地図で行ってください。右端の隠し列 `ts` と `data` は地図用なので触らないでください。
- **`Code.gs` を直したとき**：「デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ」。URLは変わりません。
- **無料の範囲**：Apps Script の無料枠（1日あたりの実行回数・時間）に対して、数人のチームの利用はごく小さいです。
- **共有をやめるとき**：`sync-config.js` を空に戻せば、これまでどおり端末だけで記録します（スプレッドシートの記録は残ります）。
