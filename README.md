# 保育園アプローチマップ（世田谷区・杉並区）

MITSU の需要調査（テレアポ → インタビュー → アンケート → モニター獲得）の進み具合を、地図で記録するツールです。
世田谷区・杉並区の保育園 483 園を地図にしています。スマホでも使えます。

- 地図：Leaflet ＋ 国土地理院「淡色地図」（無料・商用可）
- 記録：見ている端末のブラウザの中に保存（サーバーには送りません）→ CSV / JSON で書き出し・読み込み
- 参考にしたもの：高齢者絵本の `tama-senior-map`（段階の記録・端末保存・CSV）、練馬区神社マップ（スマホのシート操作）、MITSU 子どもマップ（施設と座標）

## 開き方

`起動.bat` か `index.html` をダブルクリックします。

## 使い方

- **進み方**：0 未着手 → 1 テレアポ → 2 FAX・メール → 3 日程調整 → 4 インタビュー → 5 アンケート → 6 継続的関係（モニター獲得）。断られた園は「連絡済み・ダメだった」。
- **ピンの色**
  - オレンジ＝関係が進行中（数字＝段階。5・6 は濃いオレンジ）
  - 水色（半透明）＝次に着手すべき園。推奨度 高・中・低 は詳細で自分で設定（高ほど濃く大きい）
  - グレー（半透明）＝未着手
  - 暗いグレー（半透明）＝連絡済み・ダメだった
- **進み具合の数字**：左上（スマホは下のシート）に「連絡済み ○ / 483 園・％」、進行中・インタビュー以上・モニター数。タップで段階ごと・地域ごとの内訳。
- **電話**：詳細の「📞 電話をかける」でスマホから発信。一覧の 📞 からも発信できます。通話のあと「結果をすぐ記録」（不在・かけ直し・OK・日程決定・断られた）を押すと段階と履歴が自動で進みます。園が忙しい時間帯（7:30〜9:30・11:30〜13:00・16:00〜18:30）は注意が出ます。
- **絞り込み**：🔍 から キーワード（園名・町名・住所・メモ）、区、世田谷区の地域、状態、段階、推奨度、種別、現在地からの距離、電話番号あり、次にやる日が今日まで。
- **タブ**：次に着手（推奨度をつけた未着手の園）／進行中（次にやる日が近い順）／すべて。

## 記録の保存（大事）

記録はブラウザごとに別々です。PC とスマホで記録を合わせるときは、ⓘ →「JSONで保存」→ もう一方で「JSONを読み込む」（園ごとに新しいほうが残ります）。
ときどき CSV（Excel 用）か JSON で保存しておいてください。

最初から入っている記録（`tools/seed.json`）は PC 内の資料から作った初期値です：
南八幡山（インタビュー）、松沢・烏山翼（アンケート）、上北沢こぐま・えにっくす八幡山（FAX・メール）、ベネッセ杉並和泉（インタビュー）。

## データの作り直し

```powershell
cd tools
python -I build_data.py            # 保存済みの区の一覧ページから data.js を作る
python -I build_data.py --fetch    # 区のサイトから一覧ページを取り直してから作る
```

- 施設・座標：`child-maps/setagaya.html`（子どもマップ）の世田谷・杉並分
- 電話番号・定員：世田谷区「認可保育園(定員数)」5地域、杉並区「区立保育園」「私立保育園一覧表」
- 子どもマップにない園は国土地理院の住所検索で座標を求め、`tools/geocache.json` に保存
- 区の最新一覧にない園（7園）は「閉園・名称変更の可能性」と表示し、電話番号は空です

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 地図アプリ本体 |
| `data.js` | 施設データ（自動生成。手で直さない） |
| `tools/build_data.py` | data.js を作るスクリプト |
| `tools/seed.json` | これまでの進捗の初期値 |
| `tools/src/` | 区のサイトから保存した一覧ページ |
| `tools/geocache.json` | 住所→座標のキャッシュ |
